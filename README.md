# סגל אלון לא יכרע ברוח — מדריך התקנה עצמאית

האתר רץ על **GitHub Pages** (אחסון חינמי) ו-**Firebase** של גוגל (מסד נתונים והתחברות עם חשבון Google, בחינם ובלי כרטיס אשראי). אין תלות ב-Claude.

**הקבצים:**
- `index.html`: האתר
- `runtime.js`: החיבור ל-Firebase
- `firebase-config.js`: ההגדרות (הקובץ היחיד שעורכים)
- `import.html`: ייבוא חד-פעמי של הנתונים
- `firestore.rules`: כללי האבטחה

זמן משוער: 30–40 דקות, פעם אחת.

---

## שלב 0: לפני שמתחילים
1. **ייצוא הנתונים מהאתר הנוכחי:** באתר הנוכחי ב-Claude, בלשונית **"אנשי סגל"**, לוחצים **"ייצוא כל הנתונים"** ושומרים את הקובץ `segel-alon-data-….json`. כדאי לעשות את זה ממש לפני המעבר, כדי שהנתונים יהיו עדכניים.
2. **חשבון Google משותף (מומלץ):** כדאי לפתוח חשבון Google של הסגל, למשל `segel.alon@gmail.com`, ולפתוח איתו את Firebase ואת GitHub. כך האתר לא שייך לאדם אחד. בהמשך אפשר להוסיף עוד בעלים בשני השירותים.

## שלב 1: פתיחת פרויקט Firebase
1. נכנסים ל-https://console.firebase.google.com ולוחצים **Create a project**. השם יכול להיות `segel-alon`. את Google Analytics אפשר לכבות.
2. בתפריט: **Build → Authentication → Get started**. בוחרים **Google**, מפעילים (**Enable**), בוחרים מייל תמיכה ולוחצים **Save**.
3. בתפריט: **Build → Firestore Database → Create database**:
   - מיקום: `me-west1 (Tel Aviv)`, או `eur3` אם הוא לא מופיע.
   - מצב: **Production mode**.
4. בלשונית **Rules** של Firestore מוחקים את מה שכתוב, מדביקים את כל התוכן של `firestore.rules` ולוחצים **Publish**.
   - בשורה `ownerEmails` מופיע מייל בעל האתר. אם צריך, מחליפים או מוסיפים מיילים בפורמט `['a@gmail.com', 'b@gmail.com']`.

## שלב 2: חיבור האתר ל-Firebase
1. ב-Firebase לוחצים על גלגל השיניים → **Project settings** → למטה ב-**Your apps** לוחצים על הסמל **`</>`** (Web). נותנים שם ולוחצים **Register app** (בלי Hosting).
2. מופיע קטע קוד עם `firebaseConfig`. מעתיקים ממנו לקובץ `firebase-config.js` את ארבעת הערכים `apiKey`, `authDomain`, `projectId` ו-`appId`, במקום `PASTE_HERE`.
3. ב-`ownerEmails` בקובץ צריכה להיות אותה רשימת מיילים כמו ב-`firestore.rules`.

## שלב 3: העלאה ל-GitHub Pages
1. נכנסים ל-https://github.com (עם החשבון המשותף) ולוחצים **New repository**.
   - שם: `segel-alon`.
   - סוג: **Public**. GitHub Pages חינמי רק לריפו ציבורי. הקוד יהיה גלוי, אבל **הנתונים לא**: הם שמורים ב-Firebase ומוגנים בכללי האבטחה.
2. בריפו: **Add file → Upload files**. גוררים את כל הקבצים מהתיקייה (אחרי שמילאתם את `firebase-config.js`) ולוחצים **Commit changes**.
3. **Settings → Pages**. ב-**Source** בוחרים **Deploy from a branch**, ב-**Branch** בוחרים `main` / `(root)` ולוחצים **Save**.
4. אחרי דקה-שתיים כתובת האתר תופיע למעלה, למשל `https://segel-alon.github.io/segel-alon/`.

## שלב 4: אישור הכתובת ב-Firebase
ב-Firebase: **Authentication → Settings → Authorized domains → Add domain**, ומוסיפים את הדומיין בלבד, למשל `segel-alon.github.io` (בלי `https://` ובלי הנתיב).

## שלב 5: ייבוא הנתונים
1. פותחים את `…/import.html`, למשל `https://segel-alon.github.io/segel-alon/import.html`.
2. לוחצים **כניסה עם Google** עם המייל של בעל האתר.
3. בוחרים את קובץ ה-JSON משלב 0 ולוחצים **ייבוא**.
4. בסיום יופיעו אנשי הסגל שאין להם מייל בכרטיס. בלי מייל הם לא יוכלו להיכנס, אז צריך להוסיף להם Gmail בלשונית "אנשי סגל".
5. פותחים את האתר עצמו, והכל אמור להיות שם.

## שלב 6: צירוף הסגל
- **שליחת הכתובת:** שולחים לאנשי הסגל את כתובת האתר. כל אחד נכנס עם חשבון ה-Google שלו.
- **מי שיש לו כרטיס:** מי שה-Gmail שלו מופיע בכרטיס שלו נכנס ישר.
- **מי שאין לו כרטיס:** ממלא בקשת הצטרפות, ואיש סגל מאשר אותה בלשונית "אנשי סגל".
- **הוספה מראש:** בלשונית "אנשי סגל" לוחצים **הוספת איש סגל** וממלאים את ה-Gmail שלו.
- **אם הכניסה לא עובדת:** מי שפותח את הקישור מתוך וואטסאפ או אינסטגרם צריך לפתוח אותו בדפדפן רגיל, כי גוגל חוסמת כניסה מתוך אפליקציות.

## שלב 7 (לא חובה): סנכרון חי של נגזרות הדרכה
בלי השלב הזה, מנהל או איש נע"ת הדרכה מעדכן את הנגזרות בכפתור **"טעינת קובץ אקסל"** בלשונית "נגזרות הדרכה".

כדי שהנגזרות יתעדכנו לבד מהקובץ:
1. ב-Google Drive פותחים את קובץ הנגזרות ובוחרים **קובץ → שמירה כ-Google Sheets**. מעכשיו עורכים את הגרסה הזו.
2. משתפים את הקובץ: **שיתוף → כל מי שיש לו את הקישור → צופה**.
3. נכנסים ל-https://console.cloud.google.com ובוחרים למעלה את אותו פרויקט של Firebase.
   - **APIs & Services → Library**: מחפשים **Google Sheets API** ולוחצים **Enable**.
   - **APIs & Services → Credentials → Create credentials → API key**.
   - מומלץ ללחוץ על המפתח ולהגדיר **API restrictions** ל-Google Sheets API בלבד, ו-**Website restrictions** לכתובת האתר (`https://segel-alon.github.io/*`).
4. מדביקים את המפתח ב-`sheetsApiKey` בקובץ `firebase-config.js` ומעלים את הקובץ מחדש ל-GitHub (Upload files מחליף אותו).
5. באתר: **מעקב חניכה → נגזרות הדרכה →** לוחצים על גלגל השיניים ומדביקים את הקישור לקובץ ה-Google Sheets.

מעכשיו כל פתיחה של הלשונית בודקת את הקובץ ומעדכנת אם משהו השתנה. סימוני הביצוע נשמרים.

## מה שונה מהגרסה ב-Claude
- **קבצים:** בלי העלאה ישירה. מוסיפים קישורים ל-Google Drive, וגם בסיכומי דיון מדביקים קישור.
- **יומן:** בלי כפתור "שליחת זימונים". הכפתור "הוספה ליומן שלי" עובד כרגיל.
- **התחברות והרשאות:** עם חשבון Google. אנשי הסגל לא יכולים לשנות את קוד האתר, רק להשתמש בו.

## תחזוקה
- **גיבוי:** בלשונית "אנשי סגל" לוחצים **ייצוא כל הנתונים**. כדאי לעשות את זה מדי פעם.
- **שינוי באתר:** עורכים את `index.html` ב-GitHub (סמל העיפרון). השינוי עולה לאוויר תוך דקה.
- **מגבלות:** המסלול החינמי של Firestore מאפשר עשרות אלפי קריאות וכתיבות ביום, הרבה מעבר למה שסגל גדוד צריך.
- **בעלים נוספים:** ב-Firebase דרך **Project settings → Users and permissions**, וב-GitHub דרך **Settings → Collaborators**.
